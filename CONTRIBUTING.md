# Contributing

This is a personal project. I built it for my own use and share it publicly
in case it's useful to others, but I'm not looking to maintain it as a
collaborative project.

- **I'm not accepting pull requests.** I likely won't have time to review or
  merge them, so please don't spend effort on one expecting it to land here.
- **Issues may go unanswered.** Feel free to open one, but don't expect a
  response or a fix.
- **Forking is welcome.** If you want changes, new features, or a different
  direction, please fork the repo and make it your own — that's exactly what
  the [MIT License](LICENSE) is for.
